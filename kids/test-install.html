Hier installierst du die echte Kinder-Test-Web-App für Android. Die Oberfläche ist die Kids-App – nicht die Erwachsenen-App. Änderungen werden auf diesem getrennten Teststand geprüft, bevor die öffentliche Kinder-App aktualisiert wird.

Kinder-Test-App öffnen

Auf Android installieren

  1. Öffne diesen Link auf deinem Android-Gerät in Google Chrome.
  2. Tippe auf das Menü ⋮ oben rechts.
  3. Wähle „App installieren“ oder „Zum Startbildschirm hinzufügen“.
  4. Auf deinem Startbildschirm erscheint KIDS TEST mit unserem Kinder-App-Symbol.

Diese Vorschau ist über eine eigene Test-Internetadresse erreichbar. Sie veröffentlicht keine Änderungen an der iOS-App oder der regulären Kinder-Besucher-App. Funktionen, die Schreibzugriffe auf den Server benötigen, sind in dieser Vorschau sicherheitshalber gesperrt.
