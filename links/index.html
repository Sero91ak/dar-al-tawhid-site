App installieren

Öffne zuerst dar-al-tauhid.de im passenden Browser und füge die App zum Startbildschirm hinzu.

iPhone / iPad

  1. In Safari öffnen.
  2. Auf das Teilen-Symbol tippen.
  3. Zum Home-Bildschirm wählen.
  4. Mit Hinzufügen bestätigen.

Android

  1. In Chrome öffnen.
  2. Menü ⋮ antippen.
  3. App installieren oder Zum Startbildschirm hinzufügen wählen.
  4. Installation bestätigen.
