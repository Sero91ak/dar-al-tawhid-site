Installation mit Google Chrome

  1. Öffne diese Seite in Chrome auf deinem Android-Gerät.
  2. Tippe rechts oben auf ⋮.
  3. Wähle „App installieren“ oder „Zum Startbildschirm hinzufügen“.
  4. Öffne DAR TEST anschließend über dein App-Symbol.

Diese Test-App ist getrennt von der öffentlichen Besucher-App. Neue Änderungen müssen hier geprüft und anschließend bewusst für Live freigegeben werden. Die Kids-Testvorschau ist ein gesonderter Bereich; dieser Installer leitet nicht heimlich in die öffentliche Kids-App um.

Hinweis: Das Android-Installationsfenster wird vom Browser gesteuert. Falls keine Installationsoption erscheint, zuerst Chrome aktualisieren und die Seite normal (nicht im In-App-Browser) öffnen.
