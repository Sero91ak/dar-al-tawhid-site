DĀR AL TAWḤĪD installieren

Die App lässt sich direkt zum Startbildschirm hinzufügen – ohne APK-Datei und ohne Google-Play-Download.

Auf „Web-App installieren“ tippen.

Installation über das Browser-Menü
  1. In Chrome oder Samsung Internet das Browser-Menü öffnen (⋮ oder ☰).
  2. „App installieren“, „Zum Startbildschirm hinzufügen“ oder „Seite hinzufügen“ auswählen. Der Wortlaut hängt vom Browser ab.
  3. Installation bestätigen. Anschließend die App über ihr Icon öffnen.
