# DĀR AL TAWḤĪD – Apple TV

Dieser Ordner ist der zentrale Bereich für die tvOS-/Apple-TV-App.

## Bereiche

- `hadith/` – authentische Ḥadīṯ-Datenbank für Apple TV

## Grundregel

Apple TV lädt Inhaltsdaten aus diesem GitHub-Bereich. Inhalte werden in festen IDs gepflegt, lokal auf tvOS gecacht und bei erfolgreicher Netzwerkverbindung aktualisiert. Bereits vergebene IDs werden niemals neu vergeben oder verschoben.

Aktuelle Entwicklungsquelle: Branch `staging/apple-tv-hadith`.
Nach ausdrücklicher Freigabe wird dieselbe Ordnerstruktur auf `main` verwendet.
